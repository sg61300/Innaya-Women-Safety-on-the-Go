# Brand asset pipeline

Generates the app icon set, splash frames, lockup and notification icon from a
small set of founder-supplied master PNGs using [sharp](https://sharp.pixelplumbing.com/).

## Usage

```bash
pnpm brand:build [--src=<dir>] [--allow-lowres]
```

- `--src=<dir>` — directory holding the master PNGs. Defaults to
  `./assets/brand` (the founder masters).
- `--allow-lowres` — proceed even when a master is below its minimum size,
  writing placeholder-quality output. Without it the build throws.

Outputs are written to `apps/mobile/assets/brand/`.

## Master files (inputs)

| File               | Minimum short side | Notes                          |
| ------------------ | ------------------ | ------------------------------ |
| `emblem-1024.png`  | 1024 px            | transparent, square-ish emblem |
| `lockup-1024.png`  | 600 px             | primary lockup, transparent    |
| `splash-00.png`    | 600 px             | splash frame 0, transparent    |
| `splash-01.png`    | 600 px             | splash frame 1, transparent    |
| `splash-02.png`    | 600 px             | splash frame 2, transparent    |
| `splash-03.png`    | 600 px             | splash frame 3, transparent    |
| `splash-04.png`    | 600 px             | splash frame 4, transparent    |

## Outputs (11 generated images, plus `.gitkeep` = 12 files in `apps/mobile/assets/brand/`)

| File               | Size      | Notes                                       |
| ------------------ | --------- | ------------------------------------------- |
| `icon-1024.png`    | 1024×1024 | app icon, emblem centered on transparent    |
| `adaptive-fg.png`  | 1024×1024 | Android adaptive foreground, 66 % safe zone |
| `adaptive-bg.png`  | 1024×1024 | Android adaptive background, solid `#1A0D2E`|
| `emblem.png`       | 512×512   | emblem                                      |
| `lockup.png`       | 1024 wide | primary lockup                              |
| `splash-00.png`    | 1024×1024 | splash frame 0                              |
| `splash-01.png`    | 1024×1024 | splash frame 1                              |
| `splash-02.png`    | 1024×1024 | splash frame 2                              |
| `splash-03.png`    | 1024×1024 | splash frame 3                              |
| `splash-04.png`    | 1024×1024 | splash frame 4                              |
| `notification.png` | 96×96     | white silhouette from emblem alpha          |

`app.json` (Task 16) points `icon`, `android.adaptiveIcon.foregroundImage` /
`backgroundImage`, and `notification.icon` at these files.
